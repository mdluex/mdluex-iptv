MDLUEX IPTV - INSTALL ON YOUR SAMSUNG TV
=========================================
Works on Samsung Smart TVs from 2017 and newer (Tizen), with a Windows PC on the same network.

1) ON THE TV
   - Open "Apps", then press 1 2 3 4 5 on the remote (or the on-screen number pad).
   - Switch "Developer mode" ON.
   - "Host PC IP": type this PC's IP address
     (on the PC: Settings > Network > your connection > IPv4 address).
   - Restart the TV: hold the power button on the remote until the Samsung logo appears.

2) ON THE PC
   - Extract this whole zip to a folder.
   - Double-click  Install-MdluexIPTV.cmd
   - Follow the steps on screen. The first time it will:
       * download Samsung's free Tizen tools (official, about 700 MB) - a progress bar shows how far it is.
         Windows asks permission twice: click Yes
       * open Samsung's Certificate Manager so you can create a free certificate
         with YOUR Samsung account (Samsung requires this to install apps on a TV)

3) DONE
   Mdluex IPTV opens on the TV and stays in the Apps list.
   To update: download the newer release and run the installer again (your settings are kept).

Why not USB? Samsung TVs from 2017 on only install apps from the Samsung store or through
Developer Mode, and every app must be signed for the specific TV. This installer does that for you.

Mdluex IPTV is only a player: it includes no channels or videos. Use it with your own IPTV subscription.
